# Version 1 source snapshot

This folder holds a code-only snapshot of the earlier V1 implementation as a comparison/reference. Its raw completed benchmark evidence is stored separately in `../verified_results/V1_full_gpu_benchmark_restart/`. The snapshot intentionally omits generated output folders, cached files and saved model checkpoints to avoid duplication. Use the V2 `source_code/` for the revised benchmark; do not mix its result files with V1.
