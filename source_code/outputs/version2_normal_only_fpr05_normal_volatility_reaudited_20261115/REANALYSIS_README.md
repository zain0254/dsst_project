# Clean-Normal Volatility Reanalysis

This directory contains updated metric tables and reports for the H2 high-variance FPR analysis. The original model prediction traces were not copied or modified; they are read from `../version2_normal_only_fpr05/predictions/`. No model was retrained. Only `high_variance_fpr` and `high_variance_normal_points` changed; all other metrics were independently reproduced from the saved prediction traces.
