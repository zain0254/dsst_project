   source ~/venvs/lstm_tf221_gpu/bin/activate

   python --version
   python -c "import tensorflow as tf; print(tf.__version__, tf.config.list_physical_devices('GPU'))"

IMPORTANT SCIENTIFIC QUALIFICATION:
Version 2 uses NAB labels to remove anomalous training windows and fit the scaler on normal training rows. This is a label-filtered normal-only training protocol, not a fully label-free deployment setup. Version 2 also uses a 5% validation FPR budget and validation-calibrated rolling k-sigma. It is a revised experiment and must be reported separately from Version 1.
